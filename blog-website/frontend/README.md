# Frontend Blog Website

This is the frontend application for the blog website project. It is built using React and TypeScript.

## Getting Started

To get started with the frontend application, follow these steps:

1. **Clone the repository**:
   ```
   git clone <repository-url>
   cd blog-website/frontend
   ```

2. **Install dependencies**:
   ```
   npm install
   ```

3. **Run the application**:
   ```
   npm start
   ```

   The application will be available at `http://localhost:3000`.

## Building for Production

To create a production build of the application, run:
```
npm run build
```

This will generate static files in the `build` directory that can be served by a web server.

## Folder Structure

- `src/`: Contains the source code for the application.
- `public/`: Contains the static files, including `index.html`.
- `Dockerfile`: Defines the Docker image for the frontend application.
- `package.json`: Lists the project dependencies and scripts.
- `tsconfig.json`: TypeScript configuration file.
